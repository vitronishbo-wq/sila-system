# EDUCACAO_STATUS_MATRIX.md

## Matriz de Status de Entidades

| Entidade          | Campo   | Tipo    | Status Possíveis                                                                                             |
| ----------------- | ------- | ------- | ------------------------------------------------------------------------------------------------------------ |
| Escola            | ativa   | Boolean | `True`, `False`                                                                                              |
| Turma             | ativa   | Boolean | `True`, `False`                                                                                              |
| Matricula         | status  | Enum    | `PENDENTE`, `ATIVA`, `SUSPENSA`, `CONCLUIDA`, `CANCELADA`, `TRANSFERIDA`, `APROVADO`, `REJEITADO`            |
| Enrollment        | status  | String  | (Não disponível)                                                                                             |
| Academic Identity | status  | String  | (Não disponível)                                                                                             |
