# Modulo Cooperacao Internacional

Baseline vertical funcional para cooperacao internacional com:
- Gestao de acordos e tratados (ciclo de assinatura/ratificacao/vigencia)
- Gestao de projetos de cooperacao internacional
- Gestao de vistos diplomáticos/oficiais
- Event bus + outbox em memoria
- Adapters resilientes para MRE/ONU
- API FastAPI pronta para extensao

Este baseline evita scaffolding vazio e prioriza fluxo executavel ponta-a-ponta.
