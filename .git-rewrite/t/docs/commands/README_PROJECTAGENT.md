## 💡 Pro Tips

1. **Bookmark COMMAND_REFERENCE_CARD.md**

   - Quick lookup for daily tasks
   - One-liners for common operations
   - Always keep handy

2. **Use Make as primary interface**

   - Type `make` to see all targets
   - Type `make help` for detailed help
   - Type `make <target>` to execute

3. **Check logs for debugging**

   - `make logs` shows real-time output
   - Logs saved in `logs/` directory
   - Timestamps help track issues

4. **Validate before major operations**

   - `make validate` checks everything
   - `make test` ensures code quality
   - `make audit` security review

5. **Use make down-v for clean reset**
   - Removes everything including volumes
   - Fresh start when needed
   - Useful for troubleshooting
